# SceneDiff Engineering Rules

## Before Coding

- Inspect affected files first.
- Reuse existing utilities.
- Keep API contracts backward compatible.
- Never rewrite unrelated code.

---

## Code Standards

- Small focused functions.
- Explicit naming.
- No duplicated logic.
- Typed Python and TypeScript.

---

## Commit Convention

feat:
fix:
refactor:
docs:
test:
chore:
ci:

---

## Pull Requests

Every PR must include:

- Summary.
- Files changed.
- Tests added.
- Security impact.
- Validation completed.

---

## Done Checklist

- Tests pass.
- Docker starts.
- Lint passes.
- Types pass.
- Documentation updated.
