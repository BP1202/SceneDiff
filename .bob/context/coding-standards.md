# SceneDiff Coding Standards

## Python

- Python 3.11+
- Type hints everywhere.
- Async services where appropriate.
- Small focused functions.

---

## React

- Functional components.
- TypeScript only.
- Reusable UI components.
- Tailwind utilities only.

---

## Naming

snake_case

Python.

PascalCase

Components.

camelCase

Variables.

UPPER_CASE

Constants.

---

## Imports

Standard library

↓

Third-party

↓

Internal modules

---

## Comments

Explain why.

Avoid explaining obvious code.

---

## Git

Use Conventional Commits.

One logical feature per branch.
